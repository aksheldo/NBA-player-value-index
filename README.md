# NBA Player Value Index

## Overview
This project develops an NBA player-value index that evaluates player production relative to contract value. My work focused specifically on the relationship between AST% and contract value.

## Research Question
Which NBA players provide the most production relative to their annual salary?

## Data
- Basketball Reference
- Spotrac
- 2025 NBA player statistics and contract data

## Methods
- Cleaned and combined player and salary datasets using Python
- Calculated player production metrics
- Standardized AST% across players
- Compared production measures with annual average salary
- Analyzed the resulting player-value rankings

## Results
Our analysis identified Alex Caruso, Ivica Zubac, and Jarrett Allen as the three highest-value players overall. My analysis focused specifically on AST%, for which these players ranked 15th, 44th, and 71st, respectively.

For additional visualizations, methodology, and detailed results, see the Final Results Presentation pdf.
